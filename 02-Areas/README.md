# 02 · Areas 领域

需要**长期持续投入、没有终点**的责任与角色。

## 放什么

- 长期负责的领域：工作职能、专业学习、健康、财务、人际关系
- 每个领域维护一份总览笔记，定期复盘

## 示例

| 领域 | 示例笔记 |
|------|----------|
| 职业发展 | 技能清单、行业观察 |
| 学习成长 | 读书笔记、课程总结 |
| 健康 | 运动记录、作息复盘 |

## 判断标准

问自己：**这件事需要我持续维护一辈子（或长期）吗？** 是 → 放这里。

## 处理规则

- 至少每月回顾一次，更新各领域的现状
- 领域总览中维护「下一步行动」，让责任可执行
