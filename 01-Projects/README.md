# 01 · Projects 项目

每个**有明确目标和截止日期**的事项一个文件夹，做完即归档。

## 放什么

- 有始有终的具体事项：写论文、做方案、学一门课、准备一次考试
- 每个项目一个文件夹，内含：目标说明、进度追踪、相关资料

## 文件夹模板

```
XX-项目名/
├── 项目说明.md     # 目标、截止日、成功标准
├── 进度.md         # 里程碑与当前状态
└── 资料/           # 只与本项目相关的素材
```

## 判断标准

问自己：**它有明确的「完成」状态吗？** 有 → 放这里；没有 → 考虑放 02-Areas。

## 处理规则

- 项目完成后整个文件夹移入 `04-Archive/`
- 长期没有进展的项目也要审视：继续、拆解，还是放弃归档
